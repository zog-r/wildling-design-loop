# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report privately via GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository, or open a minimal issue asking for a private contact channel.

You can expect an initial response within a few days. Please give us reasonable
time to address the issue before any public disclosure.

## Scope

This project ships configuration, prompts, and thin scripts. The most likely
security-relevant issues are: accidental inclusion of secrets or personal data,
and shell scripts that run with broader privileges than intended. Reports in
those areas are especially welcome.
